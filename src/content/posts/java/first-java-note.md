# JDK, JRE, JVM

Java를 시작할 때 가장 먼저 만나는 세 가지 용어다.

- **JDK**: Java 프로그램을 개발할 때 필요한 도구 묶음이다.
- **JRE**: 만들어진 Java 프로그램을 실행하는 환경이다.
- **JVM**: Java 바이트코드를 실제 컴퓨터에서 실행하는 가상 머신이다.

Java 소스 코드는 컴파일을 거쳐 바이트코드가 되고, JVM이 이를 실행한다.
