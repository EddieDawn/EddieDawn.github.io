## Interface

→ 완벽히 추상화된 설계도

- 기본적으로 모든 메서드가 추상 메서드
- 내부 모든 메서드가 기본적으로 추상 메서드 (public abstract 생략가능)
- 내부 모든 변수는 자동으로 public staic final (생략가능)
- ❗다중 상속 가능❗

## default Method

- 하위 호환성 제공
- 여러 인터페이스의 default method 충돌 → 구현 클래스에서 반드시 overriding

## static method

→ 인스턴스가 아닌 클래스 또는 인터페이스에 종속되어 있는 메서드

즉, 인스턴스가 있는 힙 영역이 아닌 메서드 영역에 저장이 됨.
