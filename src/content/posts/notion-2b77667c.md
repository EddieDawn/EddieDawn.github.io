## public, private, protecte, default

- public
    
    → 어디서든 접근 가능
    
- private
    
    → 같은 클래스에서만 접근 가능
    
- proteted
    
    →  같은 패키지 + 상속받은 자식 클래스에서 접근 가능
    
- default
    
    → 같은 패키지 내부에서 접근 가능
