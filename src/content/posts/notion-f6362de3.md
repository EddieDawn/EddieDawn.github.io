### 정답이 정해져 있는 경우

## 파운데이션 모델이란?

- 대량의 데이터를 기반으로 사적 학습된 대규모 AI모델
- 다양한 작업에 범용적으로 활용 가능한 기초(foundation) 역할을 함

ex) ChatGPT

→ 새로운 태스크를 위해 별도의 학습이 필요하지 않고, 자세한 프롬프트면 충분함

## 파운데이션 모델의 3가지 구성 요소

1. 빅테이터

인터넷에 존재하는 데이터의 수가 기하급수적으로 증가하고, AI모델은 학습 데이터가 늘어날수록 성능 증가

1. 자가 학습 알고리즘

사람이 정답을 알려 줄 필요가 없음. 다음 토큰 예측을 통한 텍스트 파운데이션 모델 (거대 언어 모델) 학습

1. 어텐션 기반 트랜스포머 모델
    
    어텐션: 입력 데이터에서 중요한 부분에 주의를 집중하는 메커니즘
    
    트랜스포머는 그 어텐션 메커니즘을 기반으로 한 신경망 구조를 말한다.
    

## 텍스트 파운데이션 모델

## 텍스트 파운데이션 모델이란?

- 규모의 법칙(Scaling Law) - (1)
    
    : 더 많은 데이터, 더 큰 모델, 긴 학습 → 더 좋은 성능
    
- 창발성 (Emergent Property) - (2)
    
    : 특정 규모를 넘어서면 갑자기 모델에서 발현되는 성질
    

기존 대비, (1)더 큰 모델이 더 많은 데이터에서 학습되어 (2)창발성이 나타나기 시작한 언어 모델을 **텍스트 파운데이션 모델**이라 한다.

## 거대 언어 모델의 시초: GPT-3

‘다음 토큰 예측’ 방법으로 3000억토큰의 데이터 학습 : 응답 품질 상승.
But, 다음 토큰 예측 기반의 거대 언어 모델의 한계가 있음.
→ 올바르지 않은 응답이나 유해한 응답을 생성할 수 있음.

### 정렬 (Alignment) 학습

→ 거대 언어 모델의 출력이 사용자의 의도와 가치를 반영하도록 하기

1. 지시 학습 (insturciton tuning)
    
    주어진 지시에 대해 어떤 응답이 생성되어야 하는지
    
2. 선호 학습 (preference learning)
    
    상대적으로 어떤 응답이 더 선호되어야 하는지
    

## 지시 학습 (Instruction tuning)

⇒ 주어진 지시에 대해 어떤 응답이 생성되어야 하는지
서로 다른 자연어 task를 묶을 수 있는 text기반 instruction format을 만들겠다)

사용자의 요구에 따라 작업을 바꾸는 능력을 배움.

## 선호 학습 (Preference Learning)

지시 학습은 주어진 입력에 대해 적절한 **하나의** 응답이 있다고 가정함.
하지만 정답이 정해져 있지 않은 개방형 태스크(ex 번역)에는 한계가 있음

## 선호 학습이란?

→ 다양한 응답 중 사람이 더 선호하는 응답을 생성하도록 추가학습.
→ 다양한 응답은 모델이 생성하고, 응답 간 선호도는 사람이 제공
→ 사람의 피드백을 통한 강화학습 (Reinforcement Learning from Human Feedback, RLHF)
: ChatGPT를 만들기 위한 핵심 알고리즘!

## 선호 학습 단계

### 1단계

유저로부터 다양한 지시 입력을 수집하고, 해당 입력에 대해 훈련된 사람 주석자들이 정답 데이터 생성

### 2단계

사람의 선호 데이터를 수집하여, 보상 모델(Reward Model)을 학습
AI모델이 뱉어준 응답이 얼마나 마음에 드는지 숫자 포현하기

### 3단계

1단계, 2단계에서 보지 못한 질문에 대해 사람의 추가적인 개입없이 학습된 모델들을 통해 추가 학습이 진행
지시학습된 모델을 보상 모델 기반 강화학습을 통해 한번 더 추가 학습

## 거대 언어 모델의 평가

## 평가란?

→ 구축한 시스템이 실제로 잘 동작하는지 확인하는 단계

## 평가의 3요소

- 목표
    
    시스템으로 무엇을 달성하고자 하는가
    
- 평가 방법
    
    어떤 방법으로 평가할 것인가
    
- 평가 지표
    
    어떻게 성공 여부를 판단할 것인가
    

→ 학습 단계에서 본 적 없고, 질문과 정답을 테스터가 알고 있음

### 테스트 데이터

거대 언어 모델은 다양한 테스크에 대해서 동시에 학습된다.

### 정답이 정해져 있는 경우

예측과 정답을 비교하여 일치도를 측정한다 → “정확도(Accuracy)” 예시: 벤치마크

### 정답이 정해져 있지 않은 경우 ex) 문서요약, 이야기 생성

사람이 임의의 정답을 작성 및 이와 예측을 비교
or 정답과 무관하게 생성 텍스트 자체의 품질만을 측정

## LLM-as-judge (or G-Eval)

거대 언어 모델을 통해 생성 텍스트를 평가

1. 유저는 (1)풀고자 하는 테스크 (2)평가하고자 하는 텍스트 (3)평가 기준 을 제공
2. 거대언어모델은 평가 결과(점수, 이유) 제공
3. 생성 텍스트의 “상대적 선호”를 평가할 수도 있음

### 문제점

1. 위치 편향
    
    특정 위치의 응답을 상대적으로 선호하는 편향
    
2. 길이 편향
    
    품질과 무관하게 길이가 긴 응답을 상대적으로 선호
    
3. 자기 선호 편향
    
    생성 모델이 평가 모델과 같은 경우 이를 선호 (일종의 여론조작 가능)
